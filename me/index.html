Robert Hoekstra

Independent software developer · awryLabs

I build software end to end, alone, across whatever domain the problem lives in: a strategy game for iPhone, a C++ library for graph analysis, a teaching tool for machine learning. The thread isn't a language or a stack; it's finishing things that are worth finishing — and keeping the people who use them out of the data-collection machine.

How I work

Generalist
Whatever the problem needs
Native Swift one week, C++ and Python the next, React or vanilla JS after that. I pick the tool the problem asks for rather than forcing every problem into one stack.
End to end
Idea to shipped
Design, build, write, deploy, and document, solo. No handoffs, so the thing that ships is the thing that was meant.
Privacy-first
Nothing taken
No accounts, no ad SDKs, no selling attention. The default is to collect nothing and explain plainly what little a platform unavoidably sees.
